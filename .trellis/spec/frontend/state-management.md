# Search state

Main owns one AbortController per active request. Starting a new search aborts the previous one; main only emits events for its active request. Renderer owns requestId/query/results/visibleCases/detailId/busy and ignores every stale requestId. Cancelling invalidates the renderer request ID immediately. Browse also invalidates the current search.

Preliminary results arrive before the Agent request; errors retain those results and expose retry. Clarification has at most two rounds with one key question each, only when missing subject/purpose or conflicting conditions materially affect retrieval. The renderer keeps ordered clarificationHistory question/answer pairs; append once only on an explicit reply, with busy/pending-question guards against duplicate clicks. A question response settles the current request before ranking and waits without SDK calls. Retry keeps exactly the submitted history/scope/skip flag; new queries and local navigation reset it. Skip or still-unclear exhausted rounds yield explicitly broad partial/uncertain references from stated conditions. Final Agent results are separately labelled. The renderer never treats keyword results as model judgments.

Retain preliminary results as localResults independently of agentResults. Main also includes localResults in the final response so it is self-contained if invoke resolves before queued events. Source buttons switch between Agent recommendations and all original local matches without another SDK call. Empty recommendations stay in the Agent view with an honest empty message; local results are never labelled Agent-approved. Explicit technique expansion reruns the same submitted query with allowTechniqueOnly:true; preserve that scope through answer/skip/retry and reset it for new queries/browse. Cases are grouped by relevanceTier and share one pagination limit. Reset both views and settled state on a new search or browse. Once a request settles, ignore duplicate delivery and late preliminary/progress events.

Details use detailId to reject late responses. Local card arrays are not the authoritative prompt source: detail/copy resolve the record in main.

Sidebar categories are local taxonomy navigation, never search submissions. Filter the complete overview.featured templates by category ID and cases by those templates' IDs; unassigned cases remain in all-content. Clear search continuation and Agent view state, immediately invalidate/cancel the previous request, and guard asynchronous browse results so the latest navigation or explicit search wins. Category navigation, all-content, refresh and pagination must make zero SDK calls with a configured model. Only explicit search/clarification/retry/technique expansion enters the Agent search path.
